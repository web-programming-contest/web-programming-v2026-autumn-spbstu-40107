# Лабораторная работа 1

## Задание

Вариант 15. Отцентрировать блок текста и изображение внутри контейнера,
используя разные методы центрирования:

- Flexbox для контейнера;
- абсолютное позиционирование для текста и изображения.

Изображение должно быть размещено в правом верхнем углу контейнера, текст должен
автоматически обтекать изображение.

## Реализация

Страница состоит из двух секций — по одной на каждый способ центрирования.

1. **Flexbox.** Контейнер `.flex-container` использует `display: flex`,
   `justify-content: center` и `align-items: center`, поэтому карточка с текстом
   `.text-card` находится в центре по обеим осям. Изображение внутри карточки
   имеет `float: right` и стоит в её правом верхнем углу, а текст обтекает его.
2. **Абсолютное позиционирование.** Контейнер `.absolute-container` имеет
   `position: relative`. Текстовый блок `.absolute-text` центрируется через
   `position: absolute`, `top: 50%`, `left: 50%` и
   `transform: translate(-50%, -50%)`. Изображение `.corner-image`
   позиционировано абсолютно с `top: 0` и `right: 0` — в правом верхнем углу
   контейнера.

Изображение хранится локально в `assets/landscape.svg`. На узких экранах (до
600px) во втором способе текстовый блок опускается вниз, чтобы не перекрывать
изображение.

## Запуск

Откройте `index.html` в браузере.
