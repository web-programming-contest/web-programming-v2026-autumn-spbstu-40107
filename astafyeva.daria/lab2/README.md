# Лабораторная работа 2

## Задание

Вариант 15. Реализовать функцию, которая принимает дату и возвращает строку с
описанием того, сколько времени прошло с этой даты (например, «5 минут назад»,
«2 часа назад», «3 дня назад»).

## Реализация

Файл `solution.js` экспортирует функцию `timeAgo(date)`.

1. Проверяется, что аргумент — корректный `Date`; иначе выбрасывается
   `TypeError`.
2. Считается разница `Date.now() - date` в миллисекундах. Дата из будущего —
   `RangeError`.
3. Выбирается единица измерения:
   - меньше минуты — «только что»;
   - меньше часа — целые минуты;
   - меньше суток — целые часы;
   - иначе — целые дни.
4. Вспомогательная функция `pluralize(n, forms)` подбирает русскую форму слова
   по последним цифрам числа: 1, 21 → «минуту»; 2–4, 22–24 → «минуты»; 5–20,
   11–14 → «минут».

Граничные случаи: 11–14 всегда во множественной форме («11 минут», «12 часов»),
числа округляются вниз (`Math.floor`), чтобы не завышать прошедшее время.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {timeAgo} from './solution.js';

console.log(timeAgo(new Date(Date.now() - 5 * 60 * 1000))); // "5 минут назад"
```
