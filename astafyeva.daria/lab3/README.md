# Лабораторная работа 3

## Задание

Вариант 15. Реализовать функцию `moveZerosToEnd(arr)`, которая перемещает все
нули в конец массива, сохраняя порядок остальных элементов.

## Реализация

Файл `solution.js` экспортирует функцию `moveZerosToEnd(arr)`.

1. Если аргумент не массив, выбрасывается `TypeError`.
2. За один проход по массиву элементы раскладываются в два новых массива:
   `zeros` — строгие числовые нули (`item === 0`), `nonZeros` — все остальные
   элементы.
3. Возвращается новый массив `[...nonZeros, ...zeros]`.

Решения и граничные случаи:

- исходный массив не изменяется — функция всегда возвращает новый массив;
- порядок ненулевых элементов сохраняется, так как они добавляются в порядке
  обхода;
- нулём считается только число `0` (сравнение `===`), поэтому строка `'0'`,
  `null` и `false` остаются на своих местах;
- пустой массив, массив только из нулей и массив без нулей обрабатываются без
  особых веток кода;
- сложность — O(n) по времени и O(n) по памяти.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {moveZerosToEnd} from './solution.js';

console.log(moveZerosToEnd([0, 1, 0, 3, 12])); // [1, 3, 12, 0, 0]
```
