# Лабораторная работа 1

## Задание

Вариант 20. Создать диалоговое окно, имитирующее окно подтверждения действия.
Окно содержит заголовок «Подтверждение», текст сообщения «Вы действительно
хотите удалить этот файл?» и кнопки «OK» и «Отмена». Окно должно быть
центрировано на странице.

## Реализация

Разметка находится в `index.html`, стили — в `styles.css`. Окно размещено внутри
полупрозрачного слоя `.overlay`, который занимает весь экран
(`position: fixed; inset: 0`). Центрирование выполнено через flexbox
(`align-items: center; justify-content: center`). Окно состоит из трёх блоков:
заголовок, текст сообщения и панель с кнопками.

## Запуск

Открыть файл `index.html` в любом браузере.
