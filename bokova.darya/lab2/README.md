# Лабораторная работа 2

## Задание

Вариант 20. Функция, которая преобразует RGB-строку (например, `"rgb(255,0,0)"`)
в HEX-формат (`"#FF0000"`).

## Реализация

Функция `rgbToHex(rgb)` экспортируется из `solution.js`. Регулярное выражение
проверяет формат строки и извлекает три числа. Если формат неверный или число
больше 255, выбрасывается ошибка. Каждое число переводится в шестнадцатеричную
систему через `toString(16)` и дополняется ведущим нулём через
`padStart(2, '0')`, после чего части склеиваются с префиксом `#` и приводятся к
верхнему регистру.

## Запуск

Импортировать функцию в Node.js: `import { rgbToHex } from './solution.js';` и
вызвать, например, `rgbToHex('rgb(255,0,0)')`, результат — `'#FF0000'`.
