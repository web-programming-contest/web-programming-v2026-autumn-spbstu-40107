# Лабораторная работа 3

## Задание

Вариант 20. Реализовать функцию `slidingWindowSums(arr, k)`, которая возвращает
массив сумм всех непрерывных окон длиной `k`.

## Реализация

Функция `slidingWindowSums(arr, k)` экспортируется из `solution.js` и использует
метод скользящего окна. Сначала считается сумма первых `k` элементов, затем при
каждом сдвиге окна к сумме прибавляется новый элемент и вычитается элемент,
вышедший из окна. Сложность — O(n). Если `k` меньше или равно нулю либо больше
длины массива, возвращается пустой массив. Входной массив не изменяется.

## Запуск

Импортировать функцию в Node.js:
`import { slidingWindowSums } from './solution.js';` и вызвать, например,
`slidingWindowSums([1, 2, 3, 4, 5], 3)`, результат — `[6, 9, 12]`.
