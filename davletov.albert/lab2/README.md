# Лабораторная работа 2

## Задание

Вариант 1

Реализовать функцию analyzieString, которая на вход принимает строку и
возвращает следующий объект: letters: количество букв, digits: количество цифр,
spaces: количество пробелов, other: остальные символы.

## Реализация

Функция принимает строку и подсчитывает четыре категории символов: буквы, цифры,
пробелы и всё остальное. Алгоритм: проходим посимвольно по строке циклом for.
Для классификации символа используются два регулярных выражения: \p{L} с флагом
u - определяет букву по Unicode-категории, [0-9] - определяет цифру. Проверка
идет по цепочке if / else if: сначала буква, затем цифра, затем пробел, иначе
символ попадает в категорию other. Результат накапливается в четырёх счётчиках
(letterCount, digCount, spaceCount, othCount) и в конце возвращается объектным
литералом.

## Запуск

Импортируйте именованный export из solution.js как ES module.
