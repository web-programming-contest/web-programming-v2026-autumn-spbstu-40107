# Лабораторная работа 2

## Задание

Написать функцию calculateExpression(expr), вычисляющую значение математического
выражения в строке (например, "2 + 3 * 4" → 14).

## Реализация

Функция `calculateExpression` принимает строку с математическим выражением
(например, `"2 + 3 * 4"`) и возвращает числовой результат. Она является чистой,
выполняется синхронно и не изменяет исходные данные. Строка разбивается по
пробелам на массив токенов, поэтому числа и операторы должны быть разделены
пробелами. Вычисление идёт в два прохода, чтобы соблюсти приоритет операций. В
первом проходе циклом `while` обрабатываются операторы `*` и `/`: для найденного
оператора берутся соседние числа, вычисляется результат, и три элемента (число,
оператор, число) через `splice` заменяются одним значением. Во втором проходе
массив, в котором остались только `+` и `-`, вычисляется слева направо с шагом 2
по операторам. Приоритет операций соблюдается: `"2 + 4 * 5 * 4 * 6"` → `482`.
