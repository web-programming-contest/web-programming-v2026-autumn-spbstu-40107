# Лабораторная работа 1

## Задание

Вариант 12. Создать базовый макет веб-страницы, содержащий заголовок, боковую
панель, основную часть с контентом и футер. Для вёрстки макета необходимо
использовать Flexbox или Grid. Боковая панель должна иметь фиксированную ширину
300px, а основной контент должен занимать всё оставшееся свободное пространство.
Каждый элемент макета должен иметь цвет фона, отличающийся от других элементов,
и чёрную рамку шириной 1px.

## Реализация

Разметка находится в `index.html`, стили — в `styles.css`, подключённом через
`<link>`. Макет построен на семантических тегах: `<header>` (заголовок),
`<aside>` (боковая панель), `<main>` (основной контент) и `<footer>` (футер),
которые обёрнуты в контейнер `.layout`.

Контейнер использует CSS Grid с именованными областями (сокращённое свойство
`grid-template`): заголовок и футер растянуты на две колонки, а средняя строка
разделена на боковую панель и основной контент. Колонки заданы как
`300px minmax(0, 1fr)`: боковая панель имеет фиксированную ширину 300px, а
основной контент забирает всё оставшееся пространство. Строки заданы как
`auto 1fr auto`, а `min-height: 100vh` растягивает макет на высоту окна, так что
средняя строка занимает всё место между заголовком и футером.

Каждый блок имеет свой цвет фона (жёлтый заголовок, светло-бежевая боковая
панель, песочный основной контент и кремовый футер) и рамку `1px solid #000`.
Текст внутри блоков центрируется с помощью Flexbox. Для корректных размеров
используется `box-sizing: border-box`, а `overflow-wrap: anywhere` и
`minmax(0, 1fr)` исключают горизонтальную прокрутку на узких экранах.

## Запуск

Откройте `index.html` в браузере.
