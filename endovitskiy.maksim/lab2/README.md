# Лабораторная работа 2

## Задание

Вариант 12. Реализовать функцию `formatPhoneNumber(phoneStr)` для форматирования
строки телефона под шаблон `+7 (XXX) XXX-XX-XX`.

## Реализация

Решение находится в `solution.js` и экспортирует именованную функцию
`formatPhoneNumber`.

Алгоритм:

1. Из входной строки регулярным выражением `/\D/g` удаляются все символы, кроме
   цифр. Благодаря этому функция принимает номер в любом виде: `9123456789`,
   `912 345 67 89`, `(912) 345-67-89` и т. п.
2. Если цифр 11 и первая из них `7` или `8` (номер записан с кодом страны,
   например `+7 912 345-67-89` или `8 (912) 345-67-89`), первая цифра
   отбрасывается.
3. Если после этого цифр не ровно 10, номер считается некорректным и функция
   выбрасывает `Error` с понятным сообщением, а не возвращает неверную строку.
4. Десять цифр делятся методом `slice` на группы 3-3-2-2 и подставляются в
   шаблон через шаблонную строку: `+7 (XXX) XXX-XX-XX`.

Функция синхронная, ничего не выводит в консоль и возвращает результат.

Примеры:

```js
formatPhoneNumber('9123456789'); // '+7 (912) 345-67-89'
formatPhoneNumber('8 (912) 345-67-89'); // '+7 (912) 345-67-89'
formatPhoneNumber('+7 912 345 67 89'); // '+7 (912) 345-67-89'
```

## Запуск

Импортируйте именованный export из solution.js как ES module.
