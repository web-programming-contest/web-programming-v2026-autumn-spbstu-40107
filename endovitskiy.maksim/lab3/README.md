# Лабораторная работа 3

## Задание

Вариант 12. Реализовать функцию `zipArrays(...arrays)`, которая объединяет
массивы поэлементно. Например, `zipArrays([1, 2], ['a', 'b'])` возвращает
`[[1, 'a'], [2, 'b']]`.

## Реализация

Решение находится в `solution.js` и экспортирует именованную функцию
`zipArrays`.

Функция принимает любое количество массивов через rest-параметр `...arrays`:
внутри функции `arrays` — это обычный массив из переданных массивов.

Алгоритм:

1. Если массивы не переданы, возвращается пустой массив `[]`.
2. Вычисляется длина результата — длина самого короткого массива (`Math.min` по
   длинам всех массивов). Для массивов одинаковой длины это просто их общая
   длина, а если длины разные, лишние элементы длинных массивов отбрасываются, и
   в результате не появляется `undefined`.
3. Для каждого индекса `i` от `0` до этой длины собирается кортеж из `i`-х
   элементов всех массивов (`arrays.map((array) => array[i])`) и добавляется в
   результат.

Входные массивы не изменяются: функция только читает их элементы и создаёт новые
массивы. Функция синхронная и возвращает результат.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
