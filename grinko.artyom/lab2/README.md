# Лабораторная работа 2

## Задание

Вариант 37. Реализовать функцию `formatPhoneNumber(phoneStr)` для форматирования
строки телефона под шаблон "+7 (XXX) XXX-XX-XX"

## Реализация

Экспортируемая функция `formatPhoneNumber(phoneStr: string): string` извлекает
только цифры из строки, нормализует префикс (8/ +7 -> 7, добавляет 7 для
10-значного номера) и форматирует в вид `+7 (XXX) XXX-XX-XX`.

## Запуск

Импортируйте именованный export из `solution.ts` как ES module.
