# Лабораторная работа 3

## Задание

Вариант 37. Реализуйте функцию `zipArrays(...arrays)`, которая объединяет
массивы поэлементно (например,
`zipArrays([1, 2], ['a', 'b']) -> [[1, 'a'], [2, 'b']]`).

## Реализация

Объединяет массивы поэлементно. Длина результата равна длине самого короткого
массива.

## Запуск

Импортируйте именованный export из `solution.ts` как ES module.
