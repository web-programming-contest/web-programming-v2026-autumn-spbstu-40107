# Лабораторная работа 5

## Задание

Классическая игра «Крестики-нолики» с режимами игры вдвоём и против компьютера,
полноэкранной заставкой и экраном завершения партии.

## Реализация

React хранит поле из девяти клеток, режим игры и состояние заставки. Игроки
ходят по очереди, а в одиночном режиме компьютер играет за O. Компьютер сначала
ищет выигрышный ход, затем пытается заблокировать соперника. Сетка и линия
победы рисуются на Canvas, а клетки являются кнопками.

После трёх одинаковых символов в ряд или заполнения поля появляется результат.
Из него можно начать новую партию или вернуться в меню.

## Запуск

В каталоге `lab5` выполните `npm install`, затем `npm run dev`. Команда
`npm run build` собирает приложение, а `npm run typecheck` проверяет TypeScript.
