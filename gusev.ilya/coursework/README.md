# Gadget Hub

Курсовой проект интернет-магазина по макету Figma. React + Vite на фронтенде,
Express на бэкенде. Товары и заказы хранятся в JSON, корзина — в localStorage.

Работа выполнена совместно с Олимовым Фаридуном Фарходовичем.

## Запуск

Нужны Node.js 24 и npm. Для запуска:

```sh
npm run setup
npm run dev
```

Сайт: <http://127.0.0.1:3000>. Бэкенд: <http://127.0.0.1:8080>. Вход: **admin /
12345**. Остановка: Ctrl+C.

## Возможности

Главная с каруселями, авторизация, каталог с фильтрами и сортировкой, карточки
товаров, корзина, оформление и история заказов.

## Структура

- `frontend` — интерфейс и изображения.
- `backend` — API, JSON-данные и тесты.
- `scripts` — совместный запуск фронтенда и бэкенда.

## Проверка

```sh
npm run check
```
