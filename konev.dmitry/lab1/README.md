# Лабораторная работа 1

## Задание

Разработать HTML-страницу с тремя прямоугольниками: красным, зелёным и синим.
Расположить прямоугольники в соответствии с требованиями варианта 3 и обеспечить
их частичное перекрытие.

## Реализация

Страница реализована с использованием HTML и CSS.

В файле `index.html` создан контейнер `.scene` и три элемента `div` с классами
`.red`, `.blue` и `.green`.

В файле `styles.css` заданы размеры, цвета, позиционирование и порядок наложения
прямоугольников.

Красный и синий прямоугольники имеют абсолютное позиционирование, а зелёный —
относительное. Для управления порядком наложения используется свойство
`z-index`.

## Запуск

Открыть файл `index.html` в браузере.
