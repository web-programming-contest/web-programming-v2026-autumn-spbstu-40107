# Лабораторная работа 2

## Задание

Задача 2. Написать функцию calculateExpression(expr), вычисляющую значение
математического выражения, переданного в виде строки.

## Реализация

Функция разбирает математическое выражение на числа и операторы, учитывает
приоритет арифметических операций и круглые скобки. Поддерживаются сложение,
вычитание, умножение, деление, унарные знаки и десятичные числа. Для вычисления
используется рекурсивный разбор выражения без eval(). При некорректном выражении
и делении на ноль выбрасывается ошибка.

## Запуск

Импортируйте именованный export calculateExpression из файла solution.js как ES
module.
