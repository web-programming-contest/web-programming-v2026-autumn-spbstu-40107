# Лабораторная работа 3

## Задание

Реализовать функцию findMostFrequent(arr), которая возвращает самый часто
встречающийся элемент массива.

## Реализация

Функция findMostFrequent использует Map для подсчёта количества появлений
каждого элемента массива. Во время перебора она отслеживает элемент с наибольшим
количеством появлений и возвращает его. Для пустого массива возвращается
undefined.

## Запуск

Функция экспортируется как именованный ES module export из файла solution.js.
