# Лабораторная работа 4

## Задание

Вариант 3. Разработка приложения для управления коллекцией фильмов. Реализация
класса Movie и функций для работы с массивом фильмов.

## Реализация

Реализованы класс Movie, методы добавления и удаления актёров, геттер castSize и
функции группировки и поиска фильмов. Создан пользовательский интерфейс для
добавления и удаления фильмов и актёров. Для сохранения данных используется
localStorage.

## Запуск

Открыть файл index.html с помощью расширения Live Server в Visual Studio Code.
