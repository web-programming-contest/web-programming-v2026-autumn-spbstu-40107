# Лабораторная работа 2

## Задание

Вариант 34 Создать функцию isBalanced(str), проверяющую сбалансированность
скобок ()[]{} в строке (например: "{[()]}" → true, "[(])" → false).

## Реализация

Для проверки используется структура данных стек, а так же создаётся обьект
pairs, который содержит пары скобок, и с помощью цикла проводится обход всех
символов.

Примеры граничных случаев: "()" - true " "" " - true "))" - false "{a[b(c)]}" -
true, т.к. скобки сбалансированы "abc(def)" - true, т.к. посторонние символы
игнорируются

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
