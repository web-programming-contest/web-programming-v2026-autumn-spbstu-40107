# Лабораторная работа 3

## Задание

Вариант 34 Задача 3. Реализуйте функцию findPairsWithSum(arr, sum), которая
возвращает все пары чисел, дающие в сумме sum.

## Реализация

Алгоритм использует два вложенных цикла для перебора всех возможных пар и
проверяет, не была ли найденная пара добавлена ранее. Порядок чисел внутри пары
нормализуется с помощью `Math.min()` и `Math.max()`, исходный массив не
изменяется.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
