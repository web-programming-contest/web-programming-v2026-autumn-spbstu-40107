# Лабораторная работа 1

## Задание

Вариант 35. Создать постраничную навигацию согласно макету со следующими
критериями:

- Элементы навигации должны находиться по центру;
- Текст внутри элемента навигации должен быть выровнен по центру по двум осям;
- Фон активного элемента навигации должен отличаться от остальных элементов;
- Фон элементов навигации при наведении должен изменяться.

## Реализация

- Разметка выполнена в `index.html` с использованием семантического тега `<nav>`
  и ссылок `<a>`.
- Стилизация реализована в `styles.css` с применением модели Flexbox для
  центрирования навигационной панели на странице и выравнивания символов внутри
  ссылок по горизонтали и вертикали.
- Состояние активного элемента задано через модификатор
  `.pagination__item--active`.
- Интерактивность при наведении курсора реализована с помощью `:hover`.
- Стили написаны строго по БЭМ-соглашению в kebab-case, без ID-селекторов и
  inline-стилей.

## Запуск

Откройте `index.html` в браузере.
