# Лабораторная работа 5

## Задание

Задача 5. Создать приложение финансового отчета (учет личных финансов). Аналог
MoneyLover, CoinKeeper. Реализовать добавление транзакций (расходы/доходы),
категоризацию, историю операций и визуализацию данных (графики).

## Реализация

Проект написан на React. Состояние хранится в `localStorage` (восстанавливается
при перезагрузке). Для визуализации структуры расходов по категориям применена
библиотека `recharts` (построение PieChart). Реализована форма добавления,
расчет баланса и интерактивный список истории с возможностью удаления ошибочных
транзакций. Интерфейс адаптивный.

## Запуск

`npm run dev`
