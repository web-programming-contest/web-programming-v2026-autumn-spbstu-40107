# Лабораторная работа 1

## Задание

Вариант 6. Создать меню блюд, используя неупорядоченный список. Каждый пункт
меню (`li`) состоит из названия блюда и цены: название расположено у левого края
контейнера, а цена прижата к правому краю независимо от длины названия. Каждый
пункт занимает всю ширину контейнера `ul`, ширина контейнера — 400px,
вертикальный отступ между пунктами — 16px, пункты разделены сплошной чёрной
линией толщиной 1px.

## Реализация

Меню оформлено списком `ul` с классом `menu`. Каждое блюдо — это `li` с двумя
элементами `span`: названием и ценой. Название и цена разносятся по краям с
помощью Flexbox (`display: flex` и `justify-content: space-between`).

У `ul` задана ширина 400px (с ограничением `max-width: 100%`, чтобы на узких
экранах не появлялась горизонтальная прокрутка). Каждый `li` занимает всю ширину
списка.

## Запуск

Открыть `index.html` в браузере.
