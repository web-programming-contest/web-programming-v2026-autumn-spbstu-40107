# Лабораторная работа 2

## Задание

Вариант 6. Написать функцию `isPerfectNumber`, проверяющую, является ли число
«совершенным» (сумма делителей равна числу, исключая само число).

## Реализация

Решение оформлено как ES module с именованным экспортом `isPerfectNumber`.
Функция возвращает `false` для нечисловых и нецелых значений, а также для чисел,
не превышающих 1.

Сумма делителей начинается с 1, затем перебираются числа от 2 до корня из
проверяемого числа: для каждого найденного делителя к сумме добавляется он сам и
парный делитель (число, делённое на делитель).

## Запуск

Запустить скрипт в среде с поддержкой ES-модулей
