# Лабораторная работа 3

## Задание

Вариант 6. Реализовать функцию `intersection(arr1, arr2)`, которая возвращает
массив общих элементов.

## Реализация

Решение оформлено как ES module с именованным экспортом `intersection`. Элементы
второго массива помещаются в `Set` для быстрой проверки наличия, из первого
массива оставляются элементы, которые есть во втором, а повторы убираются ещё
одним `Set`. Порядок результата соответствует порядку первого массива.

Входные массивы не изменяются. Если один из аргументов не является массивом,
функция возвращает пустой массив. Если общих элементов нет, результатом будет
пустой массив.

## Запуск

Запустить скрипт в среде с поддержкой ES-модулей
