# Лабораторная работа 4

## Задание

Вариант 6. Создать класс `Recipe` с полями `title` (название), `ingredients`
(массив ингредиентов) и `steps` (массив шагов) и методами `addIngredient`,
`removeIngredient`, а также геттером `ingredientCount`. Реализовать функции для
работы с массивом рецептов: группировка по количеству ингредиентов, уникальный
список ингредиентов, рецепты с заданным ингредиентом, группировка по количеству
шагов и список названий рецептов. Реализовать интерфейс: карточки рецептов с
названием, ингредиентами, шагами и их количеством; кнопки добавления и удаления
ингредиентов и шагов, удаления рецепта; форму создания рецепта. Все операции
добавления и удаления выполняются асинхронно через Promise и `setTimeout`,
данные сохраняются в `localStorage`.

## Реализация

Модель находится в `model.js`: класс `Recipe` с методами `addIngredient`,
`removeIngredient`, `addStep`, `removeStep` и геттерами `ingredientCount`,
`stepCount`. Функции коллекции не изменяют входной массив: группировки
возвращают `Map`, уникальные ингредиенты собираются через `Set`, поиск и список
названий используют `filter` и `map`.

Интерфейс находится в `main.js`: форма `entity-form` (поля `title`,
`ingredients`, `steps`) и карточки `entity-card` с кнопкой `delete-entity`.
Каждое изменение выполняется через Promise и `setTimeout`, сохраняется в
`localStorage` и сразу отображается на странице. После перезагрузки данные
восстанавливаются.

Открыть файл index.html с помощью расширения Live Server в Visual Studio Code.
