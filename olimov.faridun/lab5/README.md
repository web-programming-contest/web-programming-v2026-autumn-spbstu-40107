# Лабораторная работа 5

## Задание

Вариант 6. Создать компонент `Timer`, который позволяет установить время в
минутах и запускает обратный отсчёт с отображением оставшегося времени.
Компонент — функциональный, с хуками `useState` и `useEffect`. Он содержит поле
ввода количества минут (целое число), кнопку «Запуск» и отображение времени в
формате MM:SS. Запуск происходит по кнопке или по клавише Enter в поле ввода,
отсчёт обновляется каждую секунду, по завершении показывается сообщение
«Готово». Также предусмотрен сброс таймера.

## Реализация

Компонент `Timer` находится в `src/components/Timer.jsx` и использует хуки
`useState` и `useEffect`. Первый `useEffect` запускает интервал в одну секунду,
пока таймер идёт, и очищает его при остановке. Второй следит за достижением нуля
и показывает `alert` «Готово».

Поле ввода и кнопки находятся в форме, поэтому запуск по Enter и по кнопке
обрабатывает один `onSubmit`. Кнопка «Сброс» останавливает отсчёт и очищает
поле.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной и откройте
адрес, который выведет Vite.
