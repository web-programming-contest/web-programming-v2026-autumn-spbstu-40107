# Лабораторная работа 1

## Задание

Вариант 33. Создать три карточки товара с изображением размером 200 × 150 px,
заголовком Arial 18 px жирного начертания и описанием Arial 14 px. Расположить
карточки в одну строку с промежутком 20 px и задать элементам padding 10 px.

## Реализация

Каждая карточка представляет собой div с изображением, заголовком и описанием.
Карточки расположены с помощью flexbox. На узких экранах строка карточек
прокручивается внутри каталога. Фотографии хранятся в каталоге `assets`:
[Roger Varenhorst](https://unsplash.com/photos/a-pile-of-roasted-coffee-beans-HcDbE-iltf8),
[Annie Spratt](https://unsplash.com/photos/coffee-beans-QSUbfuscL3s),
[René Porter](https://unsplash.com/photos/coffee-beans-D5jUHBKSMPM) / Unsplash.

## Запуск

Откройте `index.html` в браузере.
