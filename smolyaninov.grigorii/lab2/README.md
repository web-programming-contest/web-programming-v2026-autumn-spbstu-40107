# Лабораторная работа 2

## Задание

Вариант 33. Реализовать функцию `countVowels(str)`, которая считает количество
латинских гласных `a`, `e`, `i`, `o`, `u` в строке без учёта регистра.

## Реализация

Функция последовательно проверяет каждый символ строки. Если символ входит в
набор гласных в нижнем или верхнем регистре, счётчик увеличивается. Пустая
строка и строка без перечисленных гласных дают результат 0. Функция
экспортируется по имени `countVowels`.

## Запуск

Из корня репозитория:

```bash
node --input-type=module -e "import { countVowels } from './smolyaninov.grigorii/lab2/solution.js'; console.log(countVowels('Hello, World!'))"
```

Результат: `3`.
