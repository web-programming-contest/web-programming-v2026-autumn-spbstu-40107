# Лабораторная работа 3

## Задание

Вариант 33. Реализовать функцию `shuffleArray(arr)`, которая перемешивает
элементы массива в случайном порядке.

## Реализация

Функция создаёт копию массива и проходит по ней с конца. На каждом шаге текущий
элемент меняется местами со случайно выбранным элементом от начала массива до
текущей позиции включительно. Исходный массив не изменяется; пустой массив и
массив из одного элемента возвращаются без изменения содержимого.

## Запуск

Из корня репозитория:

```bash
node --input-type=module -e "import { shuffleArray } from './smolyaninov.grigorii/lab3/solution.js'; console.log(shuffleArray([1, 2, 3, 4, 5]))"
```

Порядок элементов в результате случаен и может совпасть с исходным.
