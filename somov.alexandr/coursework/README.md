# Gadget Hub

Учебный интернет-магазин по макетам Gadget Hub. Части А и Б реализованы и объединены: React + Vite на фронтенде, Express на бекенде, JSON-файлы для товаров и заказов.

## Запуск

Нужны Node.js 22.12+ или 24 и npm. Запустите **два терминала** из папки `coursework`.

Первый терминал — сервер:

```bash
cd backend
npm ci
npm start
```

Второй терминал — интерфейс:

```bash
cd frontend
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173` (или адрес, напечатанный Vite). HTML-файл напрямую открывать не нужно: приложение запускается через Vite.

Тестовый вход:

- Логин: `student`
- Пароль: `gadget123`

API работает на `127.0.0.1:8080`. Фронтенд обращается к `/api/...`, Vite передаёт запросы серверу без префикса `/api`. При необходимости порт бекенда меняется через `PORT` в его `.env`; адрес proxy тогда тоже нужно изменить в `frontend/vite.config.js`.

Настройка `.env` не обязательна. Пример находится в `backend/.env.example`; без постоянного SESSION_SECRET при запуске генерируется случайный секрет. Сессии хранятся в памяти: после перезапуска сервера нужно войти снова. Заказы остаются в файле.

## Структура

```text
backend/
  server.js                # API, сессии, проверка и сохранение заказов
  data/
    goods.json             # 40 товаров
    users.json             # Единственная демонстрационная учётная запись
    orders.json            # Сохранённые заказы (поставляется пустым)
frontend/
  src/
    App.jsx                # Маршруты и защита страниц
    Home.jsx               # Главная и карусели
    Catalog.jsx            # Каталог
    Login.jsx              # Вход
    Cart.jsx               # Корзина и вкладки
    api.js                 # Запросы и ошибки API
    useGoods.js            # Загрузка товаров с сервера
    catalog.js             # Фильтры, сортировки и цены
    checkout.js            # Проверка формы оформления
    cart.js                # Удаление оформленных количеств
    context/               # AuthContext и CartContext
    components/            # Общие элементы, оформление, история
    styles.css
  public/assets/           # Локальная графика и Rubik
```

Код разделён по задачам; библиотеки интерфейсных компонентов, база данных и дополнительные серверные фреймворки не используются.


## Сборка

После установки зависимостей выполните npm run build в папке frontend.

## Данные

Каталог содержит 40 товаров с демонстрационными ценами. Корзина сохраняется в localStorage. Сервер рассчитывает сумму по ценам из каталога и сохраняет заказ в backend/data/orders.json. Способ оплаты записывается в заказ, деньги не списываются.

Шрифт Rubik и его лицензия OFL находятся в frontend/public/assets/fonts.
