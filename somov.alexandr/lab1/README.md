# Лабораторная работа 1

## Задание

Вариант 35, задача 1. Создать постраничную навигацию (пагинацию), которая
удовлетворяет следующим требованиям:

- элементы навигации находятся по центру страницы;
- текст внутри элемента навигации выровнен по центру по двум осям;
- фон активного элемента навигации отличается от остальных элементов;
- фон элементов навигации при наведении курсора изменяется.

## Реализация

В `index.html` навигация оформлена списком ссылок. Активная страница отмечена
атрибутом `aria-current="page"`.

В `styles.css` навигация размещена по центру страницы, а текст ссылок выровнен
по обеим осям. Активная ссылка выделена цветом; при наведении фон ссылок
меняется. JavaScript не требуется.

## Запуск

Открыть файл `index.html` в браузере — дополнительная сборка не требуется.
