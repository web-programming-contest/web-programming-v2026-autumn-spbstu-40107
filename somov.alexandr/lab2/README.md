# Лабораторная работа 2

## Задание

Вариант 35, задача 2. Написать функцию `findMissingNumber(arr)`, находящую
пропущенное число в массиве целых чисел от 1 до N (одно число пропущено). Числа
в массиве могут идти в любом порядке.

## Реализация

- `solution.js` — ES module с именованным экспортом `findMissingNumber`.
- Массив содержит все числа от 1 до N, кроме одного, поэтому
  `N = arr.length + 1`. Пропущенное число равно сумме
  `1 + 2 + … + N = N * (N + 1) / 2` за вычетом суммы элементов массива. Алгоритм
  работает за один проход и не зависит от порядка чисел.
- Функция возвращает число и не изменяет входной массив. Для пустого массива
  результат равен `1`, пропущенное первое или последнее число находится так же,
  как любое другое.

## Запуск

Импортировать функцию как ES module и вызвать:

```js
import {findMissingNumber} from './solution.js';

findMissingNumber([6, 2, 1, 5, 3]); // 4
```
