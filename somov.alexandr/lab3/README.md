# Лабораторная работа 3

## Задание

Вариант 35, задача 3. Реализовать функцию `findMedian(arr)`, которая вычисляет
медиану числового массива.

## Реализация

- `solution.js` — именованный экспорт `findMedian(arr)`.
- Массив копируется и сортируется по возрастанию числовым компаратором
  `(a, b) => a - b`, поэтому входной массив не изменяется.
- Для нечётной длины возвращается центральный элемент, для чётной — среднее двух
  центральных.
- Массив считается непустым; учитываются отрицательные и дробные числа.

## Запуск

Импортировать именованный export из `solution.js` как ES module:
`import { findMedian } from './solution.js'`, например
`findMedian([4, 1, 3, 2])` вернёт `2.5`.
