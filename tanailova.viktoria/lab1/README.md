# Лабораторная работа 1

## Задание

Вариант 38, задача 1. Создать «хлебные крошки», которые удовлетворяют следующим
требованиям:

- основа структуры — список;
- элементы списка — ссылки;
- последний элемент списка — `span`;
- цвет ссылок — `#0056ff`;
- ссылка при наведении подчёркивается снизу;
- цвет `span`-элемента — `#333`;
- стрелки между элементами реализованы через псевдо-элемент `::after`.

## Реализация

- `index.html` — `nav > ol > li`; в первых двух элементах списка ссылки
  (`Главная`, `Каталог`), в последнем — `span` (`Техника`) с
  `aria-current="page"`.
- `styles.css` — у списка сброшены маркеры и отступы, элементы выстроены в
  строку через `display: flex`. Ссылки имеют цвет `#0056ff` без подчёркивания,
  которое появляется при `:hover`; `span` имеет цвет `#333`. Стрелки `>`
  добавлены через `li:not(:last-child)::after`, поэтому после последнего
  элемента их нет.

## Запуск

Открыть файл `index.html` в браузере — дополнительная сборка не требуется.
