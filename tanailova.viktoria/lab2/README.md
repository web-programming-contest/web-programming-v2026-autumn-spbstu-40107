# Лабораторная работа 2

## Задание

Вариант 38, задача 2. Написать функцию `getZodiacSign(date)`, которая получает
дату (`Date`) и возвращает знак зодиака, соответствующий этой дате.

## Реализация

- `solution.js` — ES module с именованным экспортом `getZodiacSign`.
- Даты начала знаков хранятся в таблице `SIGNS` в порядке возрастания в виде
  `месяц * 100 + день` (например, `321` — 21 марта). Функция вычисляет такое же
  число для переданной даты по локальным месяцу и дню и берёт последний знак,
  начало которого не позже этой даты.
- До 20 января подходящих записей нет, поэтому берётся последний знак таблицы —
  Козерог, который начинается 22 декабря и заканчивается 19 января. Так
  обрабатывается переход через границу года.
- Год не учитывается, поэтому 29 февраля (Рыбы) обрабатывается так же, как
  остальные даты. Название возвращается по-русски с заглавной буквы.

## Запуск

Импортировать функцию как ES module и вызвать:

```js
import {getZodiacSign} from './solution.js';

getZodiacSign(new Date(2000, 6, 1)); // 'Рак'
```
