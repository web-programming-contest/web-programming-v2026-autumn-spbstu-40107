# Лабораторная работа 3

## Задание

Вариант 38, задача 3. Реализовать функцию `sortByFrequency(arr)`, которая
сортирует элементы массива по частоте встречаемости: более частые элементы идут
первыми.

## Реализация

- `solution.js` — именованный экспорт `sortByFrequency(arr)`.
- Частоты подсчитываются в `Map`, порядок ключей в нём соответствует порядку
  первого появления элемента.
- Пары `[элемент, частота]` сортируются по убыванию частоты (сортировка
  устойчива, поэтому элементы с равной частотой сохраняют порядок первого
  появления), затем каждый элемент повторяется столько раз, сколько он
  встречался.
- Результат — новый массив, входной не изменяется; подходят числа и строки.

## Запуск

Импортировать именованный export из `solution.js` как ES module:
`import { sortByFrequency } from './solution.js'`, например
`sortByFrequency([1, 2, 2, 3, 3, 3])` вернёт `[3, 3, 3, 2, 2, 1]`.
